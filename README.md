# CampusPlay

CampusPlay is a college sports platform demo built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## GitHub Pages

Push this project to the `main` branch of a GitHub repository. The included GitHub Actions workflow builds the app and deploys it to GitHub Pages. In the repository, open **Settings → Pages** and set **Build and deployment** to **GitHub Actions** if it is not already selected. The site URL will appear in the workflow deployment summary.
